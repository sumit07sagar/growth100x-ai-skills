# Growth100X — AI Skills & Productized Engines

Reusable Claude skills and small tools built while running [Growth100X](https://growth100x.com) client work (SEO / AEO / GEO, analytics, web builds, content). Each skill is a plain `SKILL.md` plus references and scripts, so it can be read, adapted or dropped into any Claude skills folder.

| Skill | What it does |
|---|---|
| [`seo-audit-engine`](skills/seo-audit-engine) | Live SEO / AEO / GEO audit for any domain → client PDF report + execution checklist (xlsx). |
| [`analytics-setup-engine`](skills/analytics-setup-engine) | GA4 + GTM + Search Console onboarding with a per-client tracking plan, verification and Looker Studio dashboard. |
| [`website-engine`](skills/website-engine) | Mockup-first website production: premium HTML concept, then WordPress or static (Netlify) build. |
| [`seo-client-sop`](skills/seo-client-sop) | Gated onboarding + execution SOP: classify site, audit, phased task list, worklogs, weekly reports. |
| [`meme-engine`](skills/meme-engine) | Topic → funniest angle → finished meme image + caption. |

## Small tools

| Tool | What it does |
|---|---|
| [`VoiceType`](tools/VoiceType) | Hotkey dictation on macOS (Groq Whisper + Llama cleanup), free tier. |
| [`MeetingNotetaker`](tools/MeetingNotetaker) | Records both sides of a call locally, transcribes via Groq, hands off for a recap draft. |

No client secrets, credentials or personal data are included. API keys are read from local config you create at setup.
